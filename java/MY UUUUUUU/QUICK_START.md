## 🎯 How to Use This Website

### For Website Visitors:

1. **Open index.html** in your browser to start
2. Browse through services, gallery, and about pages
3. Click "Sign Up" to create a user account
4. After registration, you'll be redirected to your dashboard
5. Click "New Booking" to make an event reservation

### For Administrators:

1. **Open admin-login.html** directly
2. Use these credentials:

## 💾 Data Storage

All data is stored in browser **localStorage**:
- **yusmad_users** - User accounts
- **yusmad_bookings** - Event bookings
- **yusmad_messages** - Contact messages
- **yusmad_admin** - Admin credentials
- **yusmad_analytics** - Revenue and statistics

**Note:** Data persists in your browser. Clear browser data to reset.

## 🐛 Troubleshooting

### If bookings don't appear:
- Check browser console for errors
- Ensure JavaScript is enabled
- Clear localStorage and try again

### If login doesn't work:
- Make sure you registered first
- Check credentials are correct
- Try creating a new account

### If admin dashboard is empty:
- Create some user accounts
- Make some bookings as users
- Send contact messages
- Refresh the admin dashboard
